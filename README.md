# E-Commerce Website

A simple e-commerce website built with Django and Tailwind CSS.
Features:
- Customer product browsing and ordering
- Simulated checkout and payment processing
- Seller dashboard using Django Admin

## Quickstart

1. Create a virtual environment: `python -m venv venv`
2. Activate it: `.\venv\Scripts\activate` (Windows) or `source venv/bin/activate` (Mac/Linux)
3. Install dependencies: `pip install django`
4. Migrate database: `python manage.py migrate`
5. Create superuser for seller portal: `python manage.py createsuperuser`
6. Run server: `python manage.py runserver`
